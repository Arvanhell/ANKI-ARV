## 🌑 Project Overview
**ANKI ARV** is a specialized, lightweight Spaced Repetition System (SRS) designed for high-stakes information retention. Built for pilots, truth-seekers, and researchers who need to maintain a local, sovereign database of knowledge beyond the reach of centralized "gatekeepers."

This tool is optimized for the **"Breakaway Knowledge"** — from propulsion physics to the deep history of the Solar System.

## 🚀 System Features
- **Sovereign Data Control:** Your deck is stored in your browser's local storage and can be fully exported/imported as a `.json` file.
- **SRS Algorithm:** Custom repetition intervals (Hard, Good, Easy) with the **"Alfa & Omega"** (30-day) finalization mode.
- **Multi-Pilot Support:** Independent decks for different user profiles.
- **Deep Space Aesthetics:** A high-contrast, neon-dark interface designed for late-night research sessions.

## 🛠️ Technical Stack
- **HTML5/CSS3:** Zero external dependencies for maximum security and load speed.
- **Vanilla JavaScript:** Clean, transparent logic for data processing.
- **Modular Storage:** LocalStorage-based persistence with manual backup capabilities.

## 🛡️ Security Protocol (Export/Import)
To maintain the integrity of your data across different nodes (devices):
1. Use the **💾 Export** button to generate a timestamped backup.
2. Transfer the `.json` file via secure channels.
3. Use the **📥 Import** button on a new device to restore the system state.
